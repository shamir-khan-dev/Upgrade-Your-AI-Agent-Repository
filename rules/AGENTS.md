# Universal Agent Operating Protocol

This file establishes the engineering standards for all AI sessions in this workspace.

### Core Standards

• Architecture First: formulate an explicit mental model of routes, components, and data structures before editing code.
• Test Driven Development: write failing automated tests first, confirm failure, implement the minimal solution, and refactor.
• Minimalism: reach for standard libraries and native language features before adding external packages.
• Clean Design: avoid neon gradients, floating glow cards, and repetitive marketing blocks. Use clean, human focused typography and deliberate spacing.
• Incremental Commits: commit small, verified, atomic changes with semantic prefixes (feat, test, fix, refactor, docs).
