# Upgrade Your AI Agent

A production grade operating protocol, curated skill library, and prompt architecture designed to transform default conversational AI assistants into rigorous, test driven Staff Software Engineers.

### The Problem With Default AI Coding Assistants

Out of the box, most conversational coding models exhibit predictable failure modes:
• Speculative Bloat: adding unnecessary libraries, wrappers, and layers when ten lines of native standard library code would solve the problem.
• Lack of Verification: assuming generated code works without writing failing automated tests first.
• AI Slop UI: defaulting to generic neon purple gradients, floating glow cards, and repetitive marketing blocks.
• Monolithic Dumps: attempting to write hundreds of lines in a single pass without atomic milestones.

This repository provides the exact operating rules, onboarding prompts, major skills, and verification harnesses required to eliminate these bad habits.

***

### The Fourteen Major Skills Included

This repository packages the fourteen core skills that power a disciplined engineering workflow:

1. Test Driven Development
Enforces the Red Green Refactor cycle. Tests must be written and proven to fail before writing production logic.

2. Ponytail Protocol
Forces the simplest solution that works. Reaches for standard libraries and native features before adding external dependencies.

3. Graphify
Constructs knowledge graphs and dependency paths across codebases, optimizing token usage by up to eighty percent.

4. Floorplan
Generates interactive architectural maps visualizing routes, modules, and data flows.

5. Spec Driven Development
Establishes clear technical specifications, scope, and acceptance criteria before writing code.

6. Planning and Task Breakdown
Decomposes large projects into ordered, atomic, verifiable implementation steps.

7. Incremental Implementation
Delivers changes in thin, verifiable slices instead of massive unreviewable blocks.

8. Unslop
Eliminates artificial intelligence design clichés from user interfaces, enforcing deliberate spacing and typography.

9. Code Review and Quality
Conducts multi axis audits for maintainability, edge cases, and performance before merging.

10. Security and Hardening
Hardens code against common vulnerabilities, enforces input validation, and checks authentication boundaries.

11. Skillspector
Security audits external agent skills and prompts for prompt injection, data leaks, and privilege escalation before installation.

12. Browser Use
Direct browser automation via DevTools and Playwright for scraping, testing, and visual verification.

13. Karpathy Guidelines
Applies behavioral guardrails to prevent common Large Language Model mistakes like unsurgical edits and silent assumptions.

14. Brag
Automatically generates polished video demos and social showcase clips directly from project source code.

### One Click Master Onboarding Prompt

Copy and paste the following prompt into your AI agent (Antigravity, Cursor, Claude Code, or ChatGPT) at the start of your project:

```text
Act as an elite Staff Software Engineer and mentor. Follow three non negotiable rules:
1. Minimalism First: write the simplest clean code using native standard libraries, no bloat or unnecessary dependencies.
2. Proof First: follow test driven development, writing automated tests before logic.
3. Zero Slop: produce bespoke production quality design without generic AI aesthetics. Plan before coding and explain your engineering decisions clearly.
```

### Repository Structure

• prompts/MASTER_AGENT_ONBOARDING_PROMPT.md: comprehensive staff engineer mentor instructions.
• prompts/QUICKSTART_PROMPT.txt: single sentence injection for rapid coding sessions.
• rules/AGENTS.md: universal drop in workspace protocol for autonomous agents.
• rules/CLAUDE.md: tailored rules for Claude Code environments.
• scripts/install_agent_os.py: one click workspace and IDE skill sync script.
• scripts/verify_setup.py: automated verification test suite checking all nineteen components.
• skills/: directory containing all fourteen curated production skills.

### Quickstart

1. Clone this repository into your workspace:
```bash
git clone <REPOSITORY_URL>
cd Upgrade_Your_AI_Agent
```

2. Run the automated verification suite:
```bash
python scripts/verify_setup.py
```

3. Install the rules and skills into any project:
```bash
python scripts/install_agent_os.py
```
